🧠 Project Overview

Claude Code Web (Gemini Edition) is a futuristic AI-powered web app that lets you:

    💻 Generate code from natural language prompts

    📖 Understand and explain code snippets

    🤖 Chat with an intelligent assistant — powered by Google Gemini API

Inspired by Anthropic’s Claude Code Web, this version is rebuilt with Gemini’s cutting-edge models for a smoother, smarter experience.

⚡ Features

    🧩 AI Code Generation: Get instant, working code from your prompts

    💬 Real-time Chat UI: Claude-style typing animation for immersive interaction

    🌌 Neon-Themed Interface: Dark mode with glowing accents for a sleek look

    🚀 Gemini API Integration: Supports gemini-2.5-flash and gemini-2.5-pro

    🖱️ One-Click Launch: Just run python app.py and you're live!

🛠️ Tech Stack
Frontend	Backend	AI Engine	Styling
HTML	Flask	Gemini API	CSS, JS

🚀 Getting Started
1. Clone the Repository
   git clone https://github.com/shibu123-dot/claude-code-web-gemini.git
cd claude-code-web-gemini

2. Install Dependencies
   pip install flask requests
   
4. Run the App
   python app.py
Open your browser and visit: 👉 https://127.0.0.1:5000

🔐 API Key Setup

To use Gemini models, you'll need an API key from Google AI Studio: 👉  https://aistudio.google.com/app/apikey
